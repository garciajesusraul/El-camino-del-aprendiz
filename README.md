# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/5eefcbf6-73bc-4147-b0f0-743fc5aadf4a

## Ejecución Local

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar el juego:
   ```bash
   npm run dev
   ```
3. Abre la dirección que aparezca en la consola (por defecto: `http://localhost:3000`) en tu navegador.
